📊 Restaurant Data Cleaning & Analysis

A beginner-friendly data cleaning and analysis project using Python and Pandas on a restaurant dataset.

📌 Project Overview

In this project, I worked with a restaurant dataset to practice the fundamentals of data cleaning, preprocessing, and exploratory data analysis using Python.

The main goal was to understand how raw data can be cleaned, organized, and explored to find useful information.

🛠️ Tools & Technologies

- 🐍 Python
- 🐼 Pandas
- 📓 Jupyter Notebook
- 📄 CSV Dataset

🔍 What I Practiced

- Loading CSV data using Pandas
- Exploring datasets
- Understanding rows and columns
- Checking data types
- Identifying missing values
- Cleaning and preprocessing data
- Filtering and selecting data
- Working with columns
- Basic data analysis
- Generating useful observations from the dataset
